# 📊 Stock Market Dashboard

A sleek, responsive stock market dashboard built using the **Alpha Vantage API**. This project helps users track real-time stock prices for major companies with a beautiful and minimal UI.

---

## 🚀 Features

- 📈 Real-time stock data using Alpha Vantage API
- 🔍 Search functionality for filtering stocks
- 📄 Pagination for easy navigation
- 🌐 Responsive and modern UI
- 🎨 Tailwind CSS + ShadCN UI integration

---

## 🛠 Tech Stack

- ⚛️ React (with Vite)
- 💨 Tailwind CSS
- 🧩 ShadCN UI (Radix + Tailwind + UI utils)
- 🔗 Alpha Vantage API
